# jtambe007.github.io

Personal portfolio site for Jacobyne Tambe, an analytics engineer specializing in Python, APIs, and data visualization.

Built with [Astro](https://astro.build) and deployed on Netlify. Theme based on [Milky-Way](https://github.com/ttomczak3/Milky-Way) by Tristen Tomczak.

## Development

| Command           | Action                                      |
| :---------------- | :------------------------------------------ |
| `npm install`     | Install dependencies                        |
| `npm run dev`     | Start local dev server at `localhost:4321`  |
| `npm run build`   | Build production site to `./dist/`          |
| `npm run preview` | Preview build locally before deploying      |

## Adding Content

- **Projects**: Add a new `.md` file to `src/content/projects/` following the frontmatter schema in `src/content.config.ts`
- **Blog posts**: Add a new `.md` file to `src/content/posts/`
- **Images**: Place static assets in `public/images/`
